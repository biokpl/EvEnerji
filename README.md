# Ev Enerji

Togg T10X şarjı, ev elektrik tüketimi ve yıllık son kaynak (SKTT) limiti takibi; akıllı prizler ve motorlu kablo sarıcı tek uygulamada.

- **Uygulama:** https://biokpl.github.io/EvEnerji/ (telefonda Chrome → Ana ekrana ekle)
- `app/` — telefon uygulaması (derlemesiz PWA, ECharts)
- `collector/` — Raspberry Pi toplayıcı servisi (Tuya prizler, eWeLink şalter, Firebase, ntfy)
- `firebase-rules.json` — veritabanı erişim kuralları
- Kurulum: [KURULUM.md](KURULUM.md)
